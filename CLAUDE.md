# Project Instructions

## Git rules

- **Never commit or push any change without explicit approval from the user.** Show the proposed changes and commit message first, then wait for a clear go-ahead before running `git commit` or `git push`.
- Commit messages must not include author trailers (no `Co-Authored-By`, `Signed-off-by`, session links, etc.) and must not mention Claude or AI assistance.
- All commits must be authored by **Gesh Giezel <geshgiezel@gmail.com>** (both author and committer).
- Once approved, always push to the `master` branch (not to feature or session branches).
